# Linux 命令教学（游戏闯关版）

深色终端风格的 Linux 命令互动学习站，单个静态 HTML 文件，无后端、开箱即用。

## 三个标签页

- **命令闯关**：十三章 79 个剧情任务（初入终端 → … → 实战综合），按完整 Linux 学习路径编排：基础命令、文件目录、权限用户、文本三剑客、管道重定向、进程管理、Python 开发、Shell/Git/打包、系统进阶、计划任务到综合实战；内置一台可写代码的模拟开发机（支持 heredoc、迷你 Python 解释器、git 模拟、tar 打包），敲对命令即时判定过关，附 75 条命令速查手册（每条示例带 `# 注释` 说明作用）
- **像素远征**：像素风 RPG，9 关卡（翡翠森林 → … → 上线之塔），在游戏终端里敲真实 Linux 命令操控像素骑士打怪过关；每关一位 NPC 可接 Python 主题支线任务；敲错扣心，按失误数评 1–3 星
- **Markdown 训练营**：12 张语法速查卡 + 12 道递进练习题，左侧写源码、右侧实时预览，检查答案即时判定

## 使用说明

- 本地预览：用浏览器直接打开 `index.html` 即可
- 顶部标签页可在三个模块间切换；标题下方有学习背景音乐栏（Web Audio 现场合成，默认关闭）和鼠标特效面板
- 进度只保存在本次打开的页面里，刷新后重新开始
