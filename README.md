# Linux 命令教学（游戏闯关版）

深色终端风格的 Linux 命令互动教学页面：五章 26 个剧情闯关任务，内置一台 2 核 4G 的 Debian 模拟虚拟机，敲对命令即时判定过关；另附 67 条命令速查手册。

## 使用说明

### 闯关模式
1. 页面顶部是「Linux 命令闯关」区：按章节顺序完成 26 个剧情任务（初入终端 → 文件功夫 → 系统侦察 → 网络探索 → 管理员之路）。
2. 每个任务包含故事背景、目标和提示：在下方模拟终端里输入命令，敲对即过关、加经验升级；卡住可点「查看提示」或「跳过这关」。
3. 顶部 HUD 显示等级、经验条、完成进度和每章星星；进度只保存在本次打开的页面里，刷新后重新开始。

### 模拟终端
- 仿真一台 Debian 12 虚拟机（2 核 / 4G 内存 / 20G 磁盘），回显复刻真机（含英文报错原文）。
- 支持 Tab 补全、上下键翻历史、Ctrl+C 中断、`sudo`（密码任意输入）、管道 `|` 和 `grep`。
- `cd` / `mkdir` / `touch` / `rm` 等会真实改变虚拟文件系统，可自由练习。

### 命令手册
页面下方的「命令手册」收录 11 个分类、67 条常用命令（中文讲解 + 一键复制示例 + 难度标记），闯关时可随时查阅。

## 本地预览与部署

- 本地预览：用浏览器直接打开 `index.html` 即可。
- 部署到 Cloudflare Pages：dash.cloudflare.com → Workers 和 Pages → 创建 → Pages 页签 → 上传资产，把 `index.html` 拖进去即可。
